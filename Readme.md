<h1>Weerradar</h1>
Weerradar is een weerapplicatie die gebruikt maakt van de buienradar json (https://data.buienradar.nl/2.0/feed/json)
Het is gemaakt in Python met behulp van de framework flask.

<h2>Features</h2>
<h3>Weerstatistieken</h3>
Kies twee datums en de programma berekent automatisch de gemiddelde temperatuur over de periode. 
Vervolgens kan je een bestand met alle gegevens van dat periode downloaden.
